# gau

Framework-agnostic authentication for web and native apps, with database adapters, OAuth providers, and framework integrations.

```sh
bun add @rttnd/gau
```

Read the [documentation](https://gau.rettend.me) for setup and usage, or browse the [example apps](https://github.com/Rettend/gau/tree/main/packages).
