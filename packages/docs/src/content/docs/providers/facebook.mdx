### Environment variables

```txt title=".env"
FACEBOOK_CLIENT_ID=
FACEBOOK_CLIENT_SECRET=
```

### Callback URL

Add the callback URL in your Facebook App under "Facebook Login" → "Settings" → "Valid OAuth Redirect URIs". Localhost URLs are automatically allowed.

```
/api/auth/callback/facebook
```

### Config

The `email` and `public_profile` scopes are requested by default.

<Aside type="note">
  Make sure to enabled the `email` and `public_profile` permissions for your Facebook App!
</Aside>

```ts title="auth.ts"
import process from 'node:process'
import { createAuth } from '@rttnd/gau/core'
import { Facebook } from '@rttnd/gau/oauth'

export const auth = createAuth({
  providers: [
    Facebook({
      clientId: process.env.FACEBOOK_CLIENT_ID,
      clientSecret: process.env.FACEBOOK_CLIENT_SECRET,
    }),
  ],
})
```

### Provider params

#### params

> Type: `Record<string, string>`
>
> Default: —

Extra query params appended to the authorization URL.
