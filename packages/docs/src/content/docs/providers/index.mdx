`gau` uses [ArcticJS](https://arcticjs.dev/) and can work with any OAuth provider, it's just a little extra work sometimes to get the user's verified email.

For email codes and magic links, use the [Email provider](/providers/email/). You can combine email and social logins in the same provider list.
