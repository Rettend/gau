## Default Permission

Connect ChatGPT accounts and stream authenticated requests to the supported OpenAI API routes. Credentials are not returned to JavaScript.

#### This default permission set includes the following:

- `allow-chatgpt-prepare`
- `allow-chatgpt-sign-in`
- `allow-chatgpt-list-accounts`
- `allow-chatgpt-sign-out`
- `allow-chatgpt-cancel`
- `allow-chatgpt-fetch`
- `allow-chatgpt-ack`
